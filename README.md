# 💼 Smart Job Recommendation System using Machine Learning

## 📌 Overview
This project recommends jobs based on user skills using Natural Language Processing and Machine Learning techniques.

## 🚀 Features
- Skill-based job recommendations
- TF-IDF vectorization
- Cosine similarity ranking
- Interactive Streamlit web app

## 🧠 ML Concepts Used
- TF-IDF (Text Vectorization)
- Cosine Similarity
- Content-Based Recommendation System
- NLP

## 🛠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit

## ▶️ How It Works
1. User enters skills
2. Skills are converted into vectors using TF-IDF
3. Cosine similarity is calculated
4. Top matching jobs are displayed
